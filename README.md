# harper-thesis

论文 *Training-Free Ultra Small Model for Universal Sparse Reconstruction in Compressed Sensing* 的代码与数据。

- `code/`：作者发布的原始 PaddlePaddle / PyTorch 脚本，保留作参照。
- `pytorch_reproduction/`：模块化、可直接运行的 CLOMP PyTorch 复现，含 1D/2D 实验、OMP/IHT 基线、指标和单元测试。

使用说明见 [pytorch_reproduction/README.md](pytorch_reproduction/README.md)。
